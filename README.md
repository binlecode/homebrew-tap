# homebrew-tap

Official Homebrew tap for [binlecode](https://github.com/binlecode) tools.

## Formulae

- **[ting (听)](https://github.com/binlecode/ting)**: Agent-first multi-source media engine with a terminal face (search, play detached via mpv, control via TUI or JSON contract).
- **[actop](https://github.com/binlecode/actop)**: Performance monitoring CLI tool for Apple Silicon.

## Installation

Install directly with full tap syntax:

```sh
brew install binlecode/tap/ting
brew install binlecode/tap/actop
```

Or tap once and install:

```sh
brew tap binlecode/tap
brew install ting
brew install actop
```

## Update

```sh
brew update
brew upgrade ting
brew upgrade actop
```
